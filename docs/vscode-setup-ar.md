# العمل على المشروع باستخدام VS Code

## ليش VS Code؟

هو الأفضل لهذا المشروع تحديدًا، ومجاني:

- دعم ممتاز لـ TypeScript و Next.js
- إضافة Tailwind تعطيك اقتراحات الأصناف وألوانها وأنت تكتب
- إضافة Prisma تلوّن ملف قاعدة البيانات وتكتشف الأخطاء
- Terminal مدمج، يعني تكتب الأوامر بنفس النافذة
- إضافة Claude Code تخليك تشتغل معي داخل المحرر مباشرة

**ما أنصح بتغييره.** البدائل مثل WebStorm مدفوعة، و Cursor هو أصلًا VS Code معدّل.
إذا حبيت Cursor، كل الخطوات أدناه تنطبق عليه حرفيًا.

---

## الخطوة ١ — تنصيب VS Code

نزّله من: https://code.visualstudio.com

---

## الخطوة ٢ — فتح المشروع

**مهم:** افتح **مجلد المشروع كاملًا**، مو ملفًا واحدًا.

من VS Code: **File** ← **Open Folder** ← اختر مجلد `mps`

> إذا فتحت ملفًا واحدًا فقط، أغلب المزايا ما راح تشتغل (الاقتراحات، فحص الأخطاء، Terminal).

---

## الخطوة ٣ — تنصيب الإضافات

أول ما تفتح المجلد، راح تظهر لك رسالة أسفل يمين الشاشة:

> **This workspace has extension recommendations**

اضغط **Install All**.

إذا ما ظهرت الرسالة:

1. اضغط `Ctrl + Shift + X` (أو `Cmd + Shift + X` على ماك)
2. اكتب في البحث: `@recommended`
3. نصّب كل الي بالقائمة

الإضافات المطلوبة (مضبوطة مسبقًا في المشروع):

| الإضافة                       | شنو تسوي                       |
| ----------------------------- | ------------------------------ |
| **Prettier**                  | تنسيق الكود تلقائيًا عند الحفظ |
| **ESLint**                    | تكتشف أخطاء الكود وأنت تكتب    |
| **Tailwind CSS IntelliSense** | اقتراحات أصناف التصميم         |
| **Prisma**                    | تلوين وفحص ملف قاعدة البيانات  |
| **Claude Code**               | الشغل معي داخل المحرر          |

---

## الخطوة ٤ — فتح Terminal داخل المحرر

اضغط: **Ctrl + `** (زر الباك-تيك، تحت زر Esc)

أو من القائمة: **Terminal** ← **New Terminal**

راح تفتح نافذة أوامر **داخل مجلد المشروع مباشرة**. منها تشغّل كل شي:

```bash
pnpm dev
```

---

## الخطوة ٥ — التعديل والمشاهدة المباشرة

1. شغّل `pnpm dev` في Terminal
2. افتح المتصفح على http://localhost:3000
3. رتّب النوافذ: VS Code على نص الشاشة، المتصفح على النص الثاني
4. عدّل أي ملف واحفظ بـ `Ctrl + S`
5. **المتصفح يتحدّث لحاله فورًا** — ما تحتاج تعيد تشغيل شي

هذي تسمى Hot Reload، وهي أهم شي في تجربة التطوير.

### جرّبها الآن

افتح ملف `messages/ar.json`، وابحث عن:

```json
"heroTitle": "اختيارك الذكي يبدأ من هنا",
```

غيّر النص واحفظ. راح تشوف التغيير بالمتصفح فورًا.

## شلون تاخذ التحديثات مني

**VS Code ما يسحب التحديثات لحاله.** لازم تطلبها.

### الطريقة الأولى: أمر واحد

من Terminal داخل VS Code:

```bash
git pull
```

خلص. VS Code راح يعرض الملفات المحدّثة فورًا بدون ما تسوي شي.

> إذا كان `pnpm dev` شغّال، أوقفه بـ `Ctrl + C` قبل السحب، وبعدين شغّله من جديد.

### الطريقة الثانية: بالضغط بدل الكتابة

1. اضغط على أيقونة **Source Control** بالشريط الجانبي (شكلها فروع متشعبة)
2. اضغط زر **⋯** بالأعلى ← **Pull**

نفس النتيجة.

### إذا التحديث فيه مكتبات جديدة

**ما تحتاج تسوي شي.** جرّبتها وتأكدت: pnpm 11 يفحص `package.json` قبل أي أمر،
وإذا لقى تبعيات جديدة ينزّلها تلقائيًا. يعني `pnpm dev` لحاله يكفي.

### إذا التحديث فيه تغييرات على قاعدة البيانات

هنا فقط تحتاج أمرًا إضافيًا:

```bash
pnpm db:deploy
```

راح أكولك صراحةً بأي مرحلة تحتاج هذا الأمر.

---

## تحديث برنامج VS Code نفسه

**يتحدّث لحاله على ويندوز.** ينزّل التحديث بالخلفية، وتشوف نقطة ملوّنة على
أيقونة الترس ⚙️ أسفل يسار الشاشة لمّا يصير جاهز — اضغطها ← **Restart to Update**.

للفحص اليدوي: **Help** ← **Check for Updates**

> تحديث VS Code ما له أي علاقة بتحديث مشروعك. اثنان منفصلان تمامًا.

## اختصارات تحتاجها

| الاختصار           | شنو يسوي                         |
| ------------------ | -------------------------------- |
| `Ctrl + S`         | حفظ (ينسّق الكود تلقائيًا)       |
| **Ctrl + `**       | فتح/إغلاق Terminal               |
| `Ctrl + P`         | فتح ملف بالاسم بسرعة             |
| `Ctrl + Shift + F` | بحث في كل ملفات المشروع          |
| `Ctrl + B`         | إخفاء/إظهار الشريط الجانبي       |
| `Ctrl + /`         | تعليق السطر                      |
| `F2`               | إعادة تسمية متغيّر في كل المشروع |

> على ماك: بدّل `Ctrl` بـ `Cmd`

## المشروع مضبوط لك مسبقًا

ملف `.vscode/settings.json` موجود داخل المشروع، ويضبط تلقائيًا:

✅ تنسيق الكود عند كل حفظ
✅ إصلاح أخطاء ESLint البسيطة تلقائيًا
✅ اقتراحات Tailwind داخل دوال `cn()` و `cva()`
✅ استخدام نسخة TypeScript الخاصة بالمشروع لا نسخة المحرر
✅ إخفاء `node_modules` من البحث

**ما تحتاج تضبط أي شي بنفسك.**

## أوامر تشغّلها من Terminal

```bash
pnpm dev          # التشغيل للتطوير — استخدمه أغلب الوقت
pnpm format       # تنسيق كل ملفات المشروع
pnpm lint         # فحص جودة الكود
pnpm typecheck    # فحص الأنواع
pnpm test         # تشغيل الاختبارات
pnpm db:studio    # تصفح قاعدة البيانات بالمتصفح
```

## مشاكل شائعة

| المشكلة                   | الحل                                                                            |
| ------------------------- | ------------------------------------------------------------------------------- |
| ما تظهر اقتراحات Tailwind | تأكد أنك نصّبت إضافة Tailwind وأعد فتح VS Code                                  |
| الكود ما ينسّق عند الحفظ  | تأكد من إضافة Prettier، ثم `Ctrl+Shift+P` ← `Format Document With` ← `Prettier` |
| خطوط حمراء تحت كود صحيح   | `Ctrl+Shift+P` ← اكتب `Restart TS Server`                                       |
| Terminal يفتح بمجلد غلط   | أغلقه وافتحه من **Terminal ← New Terminal**                                     |
| `pnpm: command not found` | أغلق VS Code كليًا وافتحه من جديد بعد تنصيب pnpm                                |

## نصيحة أخيرة

لا تعدّل هذه المجلدات أبدًا:

- `node_modules/` — تُنشأ تلقائيًا
- `.next/` — ملفات البناء المؤقتة
- `pnpm-lock.yaml` — يُدار تلقائيًا

وملف `.env` عدّله بس على جهازك، ولا ترفعه ولا تشارك محتواه.
