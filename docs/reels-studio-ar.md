# دليل استوديو الريلز

أداة لتصميم ريلز انستكرام للأجهزة — بمقاس **1080×1920 بالضبط**، بهوية MPS،
ومع حدود انستكرام الآمنة مرسومة أمامك وأنت تشتغل.

الأداة **صفحة واحدة مستقلة**، مو جزء من المتجر. ما تلمس قاعدة البيانات ولا
الـ Server Actions ولا أي شيء من كود المتجر — فما تقدر تكسر شيئاً فيه.

```
public/studio/index.html        الأداة كاملة
public/studio/assets/<جهاز>/    صور الجهاز
```

---

## 1. كيف تفتحها

```bash
pnpm dev
```

ثم افتح: **`http://localhost:3000/studio/index.html`**

ما تحتاج قاعدة بيانات ولا `.env` — الصفحة تشتغل لحالها.

---

## 2. المقاسات — وليش هي مهمة

| القيمة                  | الرقم           | السبب                              |
| ----------------------- | --------------- | ---------------------------------- |
| مقاس الإطار             | 1080×1920       | مقاس ريلز انستكرام الرسمي (9:16)   |
| عدد الإطارات            | 30 fps          |                                    |
| فراغ أعلى               | 250 بكسل        | يغطيه شريط انستكرام واسم الحساب    |
| فراغ أسفل               | 420 بكسل        | يغطيه التعليق والصوت وشريط التقدّم |
| فراغ جانبي              | 60 بكسل         | انحناء حواف شاشة الموبايل          |
| عمود الأزرار            | 240 بكسل        | إعجاب / تعليق / مشاركة على اليسار  |
| **المنطقة الآمنة للنص** | **904×1250**    | كل نص مهم لازم يكون جوّاها         |
| قص الغلاف في البروفايل  | 1080×1350 (4:5) | انستكرام يقصّ وسط الريل للشبكة     |

**كل مشهد في الأداة مبني على هذه المنطقة الآمنة أصلاً** — يعني ما راح ينزل
نص تحت تعليق انستكرام. زر «حدود انستكرام الآمنة» يوريك الحدود، والمنطقة
المظللة بالأزرق هي اللي انستكرام راح يغطيها.

> الخطوط الصفراء والمناطق المظللة **للمعاينة فقط** — ما تطلع في التصدير.

---

## 3. شاشة الأداة

- **يمين — المشاهد:** قائمة المشاهد بالترتيب. كل واحد صورة حقيقية للإطار.
  اضغط عليه لتحريره. زر `+` يضيف مشهد جديد.
- **الوسط — المعاينة:** الإطار + شريط الزمن + أزرار الخطوط الإرشادية.
  زر التشغيل يشغّل الريل كامل (أو زر المسافة من الكيبورد).
- **يسار — التحرير:** كل شيء قابل للتعديل.

---

## 4. أنواع المشاهد

| النوع       | وظيفته                                                |
| ----------- | ----------------------------------------------------- |
| **الخطّاف** | أول ٣ ثواني. رقم كبير يوقف السكرول.                   |
| **الكشف**   | ظهور الجهاز مع الاسم والجملة التسويقية.               |
| **مواصفة**  | مواصفة واحدة فقط: صورة + رقم + سطرين. كررها لكل ميزة. |
| **الألوان** | الألوان المتوفرة بصف واحد.                            |
| **السعر**   | السعر + شارة العرض + سطر التوصيل.                     |
| **الختام**  | لوكو MPS + الحساب + الهاتف + العنوان.                 |

**قاعدة واحدة لا تُكسر: مشهد = فكرة واحدة.** مشهدان بثلاث مواصفات أفضل من
مشهد بست مواصفات — المشاهد يقرأ سطراً واحداً بالثانيتين، مو ستة.

**المدّة:** خلّي كل مشهد بين ٢ و ٣ ثواني. الريل الكامل ١٥–٢٥ ثانية.

---

## 5. جهاز جديد — الخطوات

نفس الأداة تشتغل لأي جهاز وأي شركة. ما يحتاج تعديل كود:

1. **الصور:** افتح «الصور» ← «أضف صور الجهاز الجديد». الصور تبقى داخل
   متصفحك فقط وتنحفظ مع ملف المشروع.
2. **بيانات الجهاز:** غيّر الشركة والموديل والسعر.
3. **المشاهد:** لكل مشهد غيّر الرقم والوحدة والعنوان والسطر المساند واختر
   الصورة. احذف المشاهد الزايدة وضيف اللي تحتاجه.
4. **احفظ:** «حفظ المشروع» ينزّل ملف `.json` فيه كل شيء — نصوص وصور.
   «فتح مشروع» يرجّعه كما هو.

**الطريقة الأسرع:** افتح مشروع جهاز قديم، بدّل الصور والأرقام، واحفظه باسم
جديد. صار عندك قالب.

### لتثبيت صور جهاز مع المشروع

إذا تريد صور الجهاز تنفتح تلقائياً بدل ما ترفعها كل مرة:

1. حط الصور في `public/studio/assets/<اسم-الجهاز>/`
2. في `public/studio/index.html` دوّر على `const STOCK` وضيف سطر لكل صورة.

## 6. التصدير

زر **«تصدير»** يعطيك ثلاث خيارات:

- **فيديو الريل كامل** — الريل كله بالحركة، 1080×1920.
- **كل المشاهد صور PNG** — صورة لكل مشهد، للتركيب بـ CapCut أو Premiere.
- **غلاف الريل** — صورة المشهد المحدد.

**ملاحظة عن الفيديو:** المتصفح هو اللي يسجّل. كروم الحديث يطلّع **MP4**
مباشرة، ومتصفحات ثانية تطلّع **WebM** — وانستكرام ما يقبل WebM، فلازم
تحوّله بـ CapCut قبل الرفع. الأداة تقلك أي صيغة طلعت.

**الطريقة الأضمن للجودة:** صدّر PNG وركّبها بـ CapCut مع الموسيقى — هيك
تسيطر على المونتاج والصوت، والصور بدقة كاملة بدون ضغط.

## 7. الهوية — ثوابت ما تتغيّر

من دليل الهوية (`mps_logo.pdf`):

| اللون    | الكود     | الاستخدام      |
| -------- | --------- | -------------- |
| أحمر MPS | `#f22929` | اللون الأساسي  |
| أزرق MPS | `#0b1275` | ثانوي، بقلّة   |
| أصفر     | `#ffea00` | تمييز بسيط فقط |
| رمادي    | `#999999` | نص ثانوي       |

اللوكو داخل الأداة **مستخرج من ملف الهوية نفسه** مسار بمسار — مو مرسوم
بالعين — فهو مطابق ١٠٠٪.

**الخطوط:** الخط الرسمي `Gill Sans` مو متوفر على الويب. البديل داخل الأداة:
`Lato` للاتيني (أقرب خط مجاني له) و `IBM Plex Sans Arabic` للعربي — وهو نفس
خط المتجر.

**العربي ما ياخذ تباعد حروف سالب أبداً** — هذي أكثر غلطة تخلّي الخط العربي
يبين رخيص.

## 8. الأسعار والمواصفات

- **الأسعار ما تنكتب داخل الكود.** مشهد السعر يظهر مربّع فاضي مكتوب عليه
  «اكتب السعر من لوحة التحرير» لحد ما تكتبه بنفسك. هذا مقصود.
- **المواصفات راجعها قبل النشر.** المواصفات المعبّأة لـ HONOR X9d مأخوذة من
  ملخّص بحث على الإنترنت، **مو من صفحة الوكالة** — موقع honor.com محجوب عن
  البيئة اللي انبنت بيها الأداة. قارنها بورقة الوكيل وعدّلها.
